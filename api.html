Kogu skene.info sisu — kontserdid, festivalid, klubiüritused, reliisid ja merch kõigilt kolmelt saidilt (metal/rokk, räpp, klubi) — on saadaval avaliku JSON-feedina. Andmed on käsitsi kureeritud, iga kirje viitab algallikale ja feed uueneb automaatselt iga päev.

Otspunktid

https://www.skene.info/feed/events.json

Tulevased ja värsked kirjed, kõik kolm saiti koos. Vastus: {"updated", "count", "entries": [...]}.

https://www.skene.info/feed/archive.json

Arhiiv — kõik möödunud kirjed alates saidi avamisest, sama formaat.

https://www.skene.info/api/kalender?g=punk&c=Tartu&s=www

Kalendritellimus (iCalendar). Tagastab text/calendar — vali sobiv filter ja telli see oma kalendrisse, siis lisanduvad uued üritused sinna automaatselt. Kalendrirakenduses ava webcal://-lingina (saidil on selleks nupp „Telli see valik oma kalendrisse"). Parameetrid, kõik valikulised ja kombineeritavad: g = žanrisildid komadega (VÕI-loogika, toorsildid, mitte saidi žanrichippide nimed), c = koht, t = tüüp, s = saidid komadega (www, rap, klubi). Möödunud ja tba-kirjed jäetakse välja. 16.08.2026.

Kasutamine

Feed on vabalt kasutatav. Kaks palvet: viita andmete juures skene.info-le ja hoia iga kirje algallika link (su/ou) alles — sait elab traffic-eetikast, kus liiklus jõuab korraldajateni. Vigadest ja puuduvatest üritustest anna teada esilehe kontaktivormi kaudu.

Tehniline märkus: vastustel on CORS-päis (Access-Control-Allow-Origin: *), nii et feedi saab lugeda ka otse brauseri-JavaScriptist (fetch) ükskõik milliselt domeenilt — serveripoolsest kasutusest rääkimata.

Feed uueneb iga päev ~07.30 ja iganädalase andmekorje järel.

Everything on skene.info — concerts, festivals, club nights, releases and merch from all three sites (metal/rock, rap, club) — is available as a public JSON feed. The data is hand-curated, every entry links to its original source, and the feed updates automatically every day.

Endpoints

https://www.skene.info/feed/events.json

Upcoming and fresh entries, all three sites combined. Response: {"updated", "count", "entries": [...]}.

https://www.skene.info/feed/archive.json

Archive — everything past since the site launched, same format.

https://www.skene.info/api/kalender?g=punk&c=Tartu&s=www

Calendar subscription (iCalendar). Returns text/calendar — pick a filter and subscribe to it, and new events show up in your calendar automatically. Open it as a webcal:// link (the site has a „Subscribe to this selection" button). All parameters are optional and combinable: g = genre tags, comma-separated (OR logic, raw tags, not the site's genre chip names), c = place, t = type, s = sites, comma-separated (www, rap, klubi). Past and tba entries are excluded. Added 2026-08-16.

Entry fields

fieldmeaning
saitsite: www (metal/rock/punk), rap or klubi (club)
d, d2date YYYY-MM-DD; multi-day events end as DD.MM
ttype: kontsert (concert) / festival / klubi (club night) / reliis (release) / merch / muu (other)
n, aname and short description
bperformers (exactly as the event's own source lists them)
v, c, linnvenue and city (c: "mujal" + linn outside the main cities)
ggenre tags. Spelling is normalised (one genre = one form): in the rap feed hiphop, hip-hop and rap are all räpp; in the club feed eksperimentaal → experimental. Changed 2026-08-15.
sn, sudiscovery source name and link — please keep attribution
on_, ouorganiser / the event's own page
pu, hindticket link and price ({praegu, mark, allikas}; absent when unconfirmed)
imgcover image, full URL
rel, lisatudrelease flag and date added (a release counts as "new" for 30 days from adding)

Usage

The feed is free to use. Two requests: credit skene.info next to the data, and keep each entry's original source link (su/ou) — the site runs on traffic ethics, where clicks reach the organisers. Report errors or missing events via the front-page contact form.

Technical note: responses carry a CORS header (Access-Control-Allow-Origin: *), so the feed can be read directly with browser JavaScript (fetch) from any domain — server-side use works too, of course.

The feed updates daily at ~07:30 EET and after each weekly sweep.
